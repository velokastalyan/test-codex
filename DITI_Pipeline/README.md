# DITI Pipeline

DITI_Pipeline is a self-contained folder that manages the documentation pipeline for macOS automation. Markdown is the single source of truth; readable RTF outputs and an upload-ready Markdown pack are generated from it.

## Source of Truth

- **Markdown** is authoritative: `DITI_Pipeline/docs/**/*.md`, plus `DITI_Pipeline/README.md` and `DITI_Pipeline/CHANGELOG.md`.
- **RTF mirror** is autogenerated into `DITI_Pipeline/Automat/`.
- **UPLOAD_MD pack** is rebuilt into `DITI_Pipeline/Automat/UPLOAD_MD/`.

## Scripts

- `05_tools/docs_export_to_automat.sh` — converts Markdown to readable RTF using `textutil`.
- `05_tools/docs_pack_for_chatbot.sh` — rebuilds `Automat/UPLOAD_MD` and writes `MANIFEST.txt`.
- `05_tools/docs_watch.sh` — watches for docs changes and runs export + pack.

## Install the Watcher (one command)

```sh
./05_tools/docs_watch_install.sh
```

To uninstall:

```sh
./05_tools/docs_watch_uninstall.sh
```

## Logs

All logs are written under `DITI_Pipeline/04_logs/`:

- `docs_export_<TS>.log`
- `docs_pack_<TS>.log`
- `docs_watch_current.log`

## Automator Role

Automator is only used for the **image pipeline**. Documentation outputs do **not** use Automator; they are generated by shell scripts and stored in `Automat/` for macOS-friendly consumption.
